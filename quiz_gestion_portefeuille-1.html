📖 Lexique des notations (à lire si tu débutes)
  • $x_p$, $x_b$ : poids (part en %) d'un secteur dans le portefeuille / dans le benchmark (l'indice de référence)
  • $r_p$, $r_b$ : rendement du portefeuille / du benchmark
  • $M$, $S$, $I$ : effets Market timing, Sélection, Interaction (Brinson)
  • $IR$ : ratio d'information ; $TE$ : tracking error (écart-type de $r_p - r_b$) ; $\sigma$ : volatilité
  • $T$ : horizon en années ; $t$ : statistique de Student
  • $D$ : duration ; $D^*$ : duration modifiée ; $\Delta r$ : variation des taux
  • $A$, $L$ : actif et passif (engagements) ; $f = A/L$ : funding ratio ; $\pi$ : surplus
